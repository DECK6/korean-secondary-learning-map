# v0.5.0-candidate 릴리스 보고서

릴리스 기준일: 2026-07-17

## 변경 목적

v0.4는 공식 근거 관계 101건 위에 문서 배열 기반 탐색 순서 52,191건을 함께 수록했다. 소유자 결정에 따라 v0.5는 **공식 문서가 직접 뒷받침하는 관계만** 제품에 남긴다. 이 학습지도의 목적은 공식 교육과정 안에서의 학습 추적이며, 공식 범위를 벗어난 저장소 추론 관계는 그 목적에 부합하지 않기 때문이다.

## 핵심 변경

1. **AI 작성(repository-authored) 관계 전면 삭제**: 중학교 2,125건, 고등학교 49,990건, 학교급 bridge 과정 수준 37건. builder에서 생성 경로 자체를 제거했고, 스키마가 `repository-authored` 학습 관계를 거부한다.
2. **공식 문서 채굴을 전 교과로 확장**: 수학 파일럿(내용 체계표 학년 진행 + 성취기준 해설 인용)을 중학교 전 과목과 고등학교 전 교과(일반·교양·계열·직업계 전문교과 별책 5~39)에 적용했다. 과목별 사양은 `scripts/lib/official-relation-specs/`의 46개 데이터 모듈로 고정하며, 각 모듈은 과목별 검토 문서(`docs/reviews/2026-07-17-*.md`)와 짝을 이룬다.

## 채굴 증거 규칙

- C계층: 내용 체계표의 학년(군) 진행이 같은 갈래의 내용 요소 선후를 직접 보여줄 때 (중학교 내부는 1~3학년 단일 학년군이라 대부분 0건 — 수학만 예외).
- D계층: 성취기준 해설·적용 시 고려 사항·과목 성격이 선행 학습을 명시 지목("~을 토대로", "~을 바탕으로", "~을 이수한 후")할 때.
- 공식 문장이 학습 영역 전체를 지목한 경우 해당 영역 성취기준으로 기계적으로 전개하고 검토 문서에 전개 방식을 기록.
- 직업계 전문교과는 편성 기준·해설의 명시 문장만 인정, NCS 능력단위 나열 순서는 근거로 사용하지 않음.
- 근거가 없으면 빈 배열. 문서 배열 순서·교육적 추론 금지.

## 후보 층 추가 (2026-09-05)

K-12 공통 계약 v1(`docs/plans/2026-09-05-k12-relation-vocabulary-spec.md`)에 따라 관계를 2층으로 분리했다. 릴리스 ID(`kr-2022-{middle,high,middle-high-bridge}-v0.5.0-candidate`)와 데이터 버전 문자열은 바꾸지 않았다.

1. **official 층 표시**: `data/kr/{middle,high}/learning-relations.json`과 `data/kr/bridges/elementary-transitions.json`의 모든 레코드에 `layer: "official"`을 추가했다. official 프로필은 `basisKind: official-source`, `relationKind: required-prerequisite`만 허용한다.
2. **고등학교 토픽 투영 39건 제거**: 과목 설계 연계 문장을 "과목 A의 마지막 성취기준 → 과목 B의 첫 성취기준"으로 투영한 `recommended-before` 학습 관계 39건을 official 학습 관계에서 뺐다. 계약이 official 층을 전건 `required-prerequisite`로 정의했고, 같은 근거의 과목 수준 관계 39건이 `high/course-relations.json`에 그대로 있어 근거 손실이 없다. 고등학교 official 학습 관계는 508 → 469건.
3. **후보 층 신설**: `scripts/build-candidate-relations.mjs`(`bun run build:candidates`)가 `data/kr/{middle,high}/learning-relations.candidate.json`을 생성한다.

| 규칙 | basisKind | 중학교 | 고등학교 |
| --- | --- | ---: | ---: |
| `R-CODE` 같은 과목·영역의 인접 성취기준 코드 | `official-code-order` | 542 | 2,353 |
| `R-FACET` 핵심 주제 → 같은 성취기준의 facet 주제 | `decomposition-order` | 1,446 | 0 |
| 합계 | | **1,988** | **2,353** |

고등학교 후보는 `programScopes`에 `all-high-schools`가 있는 과목만 대상으로 하며 직업계 전문교과 528과목은 0건이다. 합집합 DAG를 지키기 위해 순환을 만드는 고등학교 후보 간선 3건을 결정적으로 제외했다. 후보 층은 중학교 24/24 과목, 고등학교 비직업계 231/231 과목을 덮으며, 두 층을 합치면 고등학교 공통·일반 선택 66개 과목 중 관계 0건 과목이 없다.

4. **facet 공통 어휘**: 중학교 주제의 과목별 24종 키를 `facetKeyDetail`로 옮기고 `facetKey`에 공통 8종(`concept`·`procedure`·`representation`·`application`·`inquiry`·`communication`·`reflection`·`core`)을 담았다. 고등학교 주제는 `facetKey: core`다. 주제 ID 해시 입력은 `facetKeyDetail`이라 중학교 2,160·고등학교 50,749개 주제 ID가 모두 불변이다. 사상 근거는 `docs/decisions/2026-09-05-facet-mapping.md`.
5. **온톨로지**: `slm:layer` 속성, `slm:OfficialLearningRelation`·`slm:CandidateLearningRelation` 하위 클래스, `slm:facetScheme` SKOS 8개념, `slm:facetKeyDetail`을 추가했다. SHACL `slm:OfficialLearningRelationShape`가 official 클래스에 후보 층 값이 들어오면 거부하며, 적대 fixture `bad:candidate-in-official-layer`(위반 코드 `CANDIDATE_IN_OFFICIAL_LAYER`)로 회귀를 막는다.
6. **인쇄 쪽번호 정정**: `scripts/lib/official-relation-specs/math.mjs`가 PDF 페이지를 인쇄 쪽번호로 인용하고 있었다(별책8 PDF 페이지 − 6 = 인쇄 쪽번호). 62개 튜플을 인쇄 쪽번호로 정정했다. 나머지 45개 모듈은 원문 대조 결과 이미 인쇄 쪽번호를 쓰고 있었다. `docs/reviews/2026-07-13-math-learning-relations-review.md` 정정 절 참조.

## 초→중 bridge 정비·확장 (2026-09-05)

7. **초등 인벤토리 재핀**: `data/kr/bridges/elementary-topic-inventory.json`을 초등 `kr-full-depth-v0.5`(주제 1,956, 성취기준 620)로 재생성했다. 인벤토리는 이제 topicId 목록에 더해 성취기준별 코드·교과·영역·학년군·대표 주제·주제 목록과 초등 manifest의 `topics.json` sha256 핀을 담는다. 재생성은 `bun scripts/dev/pin-elementary-inventory.mjs <초등 저장소 경로>`다. 2026-1판 통합교과 재작성으로 초등 주제 ID 48개가 사라졌지만 이를 참조하는 bridge는 0건이라 official에서 제외한 관계는 없다.
8. **facet 선택 규칙 통일**: 사양 모듈 튜플의 초등 topicId에서 성취기준을 역산해 그 성취기준의 `facetKey: concept` 주제로 `prerequisiteTopicId`를 재선택한다(초등 영어 20건은 인벤토리에 concept facet가 없어 정렬상 첫 주제 = `communication`, 문서화된 예외). 초등 선수 주제 127건이 옮겨졌고 접미사 분포는 `concept` 110/`perform` 64/`.01` 38/… 에서 `concept` 270 + `communication` 20으로 통일됐다. 관계 ID 해시 씨앗은 튜플의 원래 topicId를 유지하므로 290건의 관계 ID와 `bridges/review-records.json`의 `targetIds`는 불변이다. 매핑표는 `docs/reviews/2026-09-05-bridge-facet-normalization.md`.
9. **초→중 후보 층 신설**: `data/kr/bridges/elementary-transitions.candidate.json` 3,180건(`layer: pedagogical-candidate`, `relationKind: recommended-before`, `scope: cross-school-level`, `basisKind: repository-authored`). 규칙 `R-DOMAIN-CONTINUITY`는 내용 체계표가 초등 5~6학년군과 중학교를 같은 영역 계열로 제시하는 경우에만 적용하며, 영역 대응표는 `scripts/lib/bridge-domain-map.mjs`에 10개 교과 57개 영역 쌍으로 명시했다. 사회·역사는 두 저장소의 `domain`이 모두 단원명이라 영역 대응을 확정할 수 없어 비워 뒀다. official 쌍 193건은 후보에서 제외했고, 두 층과 합집합 모두 DAG다. 근거·한계는 `docs/reviews/2026-09-05-bridge-domain-continuity.md`.
10. **커버리지 지표**: `data/kr/relation-coverage-report.json`의 `bridges` 절에 `middleStandards` 714, `middleStandardsWithOfficialBridge` 259(36.27%), `middleStandardsWithAnyBridge` 447(62.61%)을 기록한다. 개선계획 P2-3의 목표(60% 이상)를 충족한다.
11. **UI**: 전이 지도에 "초등학교에서 중학교로" 절을 추가하고 층(공식 문서 근거 / 권장(후보))·중학교 과목·검색 필터를 붙였다. 레코드는 `ui/data/elementary-bridges.json`으로 분리해 탭을 처음 열 때만 내려받는다.

## 남은 한계

- `internal-reviewed`는 저장소 내부 검토(소유자 승인 범위)이며 교과 전문가·학교 현장 승인이 아니다.
- 세부 주제(facet) 분해·요약·증거·평가 질문은 여전히 저장소 생성물(`mechanical-derivative`, `candidate`)이다. 공식 근거 원칙은 관계에 적용되었다.
- 영역 지목 문장의 성취기준 전개는 기계적 규칙이므로 교과 전문가의 표본 검토가 필요하다.
- 공식 문서는 국가가 공표한 공개 자료이며(권리 상태 `cleared`), 저장소는 원문을 수록하지 않고 출처 locator로 연결한다.
